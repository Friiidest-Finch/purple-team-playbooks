# T1059.001: Command and Scripting Interpreter: PowerShell

| Field | Isi |
|-------|-----|
| Taktik | Execution |
| Platform | Windows |
| Sumber referensi | https://attack.mitre.org/techniques/T1059/001/ |
| Status | Draft |

## 1. Ringkasan
Penyerang sering memakai PowerShell karena sudah tersedia di Windows dan bisa dipakai tanpa menaruh file di disk. Pola yang umum dicurigai: perintah ter-encode (`-EncodedCommand`), eksekusi dari proses induk tak biasa (mis. Office), dan download-cradle.

## 2. Simulasi (hanya di lab)
- Gunakan **Atomic Red Team**: lihat daftar test untuk T1059.001 di
  https://github.com/redcanaryco/atomic-red-team/tree/master/atomics/T1059.001
- Jalankan lewat `Invoke-AtomicRedTeam` pada VM lab yang sudah di-snapshot.
- Catat waktu eksekusi (UTC) untuk dicocokkan dengan log.

## 3. Telemetri yang Diharapkan
| Sumber | Event ID | Catatan |
|--------|----------|---------|
| Sysmon | 1 | Process Create (CommandLine, ParentImage) |
| Windows Security | 4688 | Perlu "Include command line" aktif |
| PowerShell Operational | 4103, 4104 | Module & Script Block Logging |

**Prasyarat logging:** aktifkan Script Block Logging dan Module Logging via GPO.

## 4. Deteksi
- Sigma: `detections/sigma/proc_creation_win_powershell_encoded_command.yml`
- Ide hunting tambahan:
  - PowerShell dengan parent `winword.exe`, `excel.exe`, `outlook.exe`
  - Script Block (4104) berisi string `DownloadString`, `IEX`, `FromBase64String`

## 6. Gap & Remediasi
- Aktifkan **PowerShell Constrained Language Mode** untuk user non-admin
- Aktifkan **AMSI** dan pastikan EDR/AV membacanya
- Terapkan **AppLocker / WDAC** untuk membatasi eksekusi
- Hapus **PowerShell v2** (`Disable-WindowsOptionalFeature -Online -FeatureName MicrosoftWindowsPowerShellV2Root`)
- Kirim log PowerShell ke SIEM terpusat
